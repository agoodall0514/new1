TEXAS LAW OFFICER AI — INSTALLABLE WEB APP

This is a Progressive Web App (PWA). It can be hosted on HTTPS and installed on an iPhone/iPad.

IPHONE INSTALL:
1. Host these files on an HTTPS website.
2. Open the site in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Open the Texas Law Officer AI icon.

IMPORTANT:
This package is the installable interface/prototype. Live AI requires a secure server-side backend. Never put an AI API key in app.js.

PRODUCTION:
iPhone PWA -> HTTPS backend -> privacy/PII filter -> AI + authoritative Texas-law retrieval -> answer.
The production legal engine should show exact current statutory text, plain-language explanation, elements, facts supported, missing facts, report considerations, related law/case law, and current source/date.
